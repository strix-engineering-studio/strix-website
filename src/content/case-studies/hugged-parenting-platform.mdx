## Product context

Hugged is a community-based parenting platform that required a connected experience across its mobile application, web interfaces, backend services, payments, and community notifications.

## Engineering delivered

- Flutter mobile application development and release engineering
- Next.js public website and administrative console
- Firebase Cloud Functions, Cloud Firestore, and related Firebase services
- Razorpay payment integration and server-side payment workflows
- Firebase Cloud Messaging token management and push notifications

## Outcome

The Android application is live on Google Play and the public website is available at [hugged.in](https://hugged.in). The engagement also includes the web console, Firebase-backed services, Razorpay integration, and notification workflows. iOS distribution is being processed.

## Technology

Flutter, Dart, Next.js, TypeScript, Firebase, Cloud Firestore, Cloud Functions, Firebase Cloud Messaging, and Razorpay.
